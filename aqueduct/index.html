このレシピの前提

対象はパッチ7.55の庭具「ルインド・アクアダクト」の中間素材3種（部材/金属材/錬金樹脂）。3種ともレシピ数値は同一の高難度（エキスパート）レシピで、マイスター必須・レベル100・お手伝い製作/簡易製作不可。状態変化がランダムに出るためマクロは組めず、手打ちで状態に合わせて判断する。各2個、計6回の高難度製作を完走する必要がある。

本体の組み立て（彫金、中間素材×各2＋カットストーン×7＋ヤクテル淡水×7）は工数10040・HQなし・品質要求なしの通常レシピ。素材さえ揃えばリスクはない。勝負はこの中間素材だけ。

  • 必要作業精度 5620（コスモツール最終＋新式防具 5779 なら余裕をもって通過）
  • 初期品質0%。品質31500以上で完成させないと素材ロスト（製作失敗扱い）
  • 成功率の目安: 新式フル禁断＋食事薬で体感4〜5割、コスモツール最終（スターズ）なら9割前後（SNS実勢）。それでも失敗はあるので素材は多めに用意する
  • クラフターの設計図を忘れずに持ち込む。設計変更・一心不乱・クイックイノベーションは1回使うごとに1枚消費（フル活用で最大5枚/製作、6個作るなら30枚）。スクリップ交換で事前補充

実機モードとリカバリー（本番での使い方）

  • 実機モードにすると状態変化の抽選が止まり、毎ターン「ゲーム画面に出た状態」をタップで入力する方式になる。突貫作業の成否も入力制。ゲームと同じ手を同じ順で押していけば、CP・ターン数・IQをシミュ側が自動計算してくれる
  • それでもズレたら（押し間違い等）「リカバリー入力」ボタンで工数・品質・耐久などを実機の値に直してその地点から再開。CP・ターン・IQは計算値がプリセットされるので、合っていればそのまま再開でよい
  • バーの下の勝算判定が毎ターン更新される。「続行推奨（無風でも届く）／お祈り圏（高品質頼み）／見切り推奨」の3段階。見切りになったら粘らず、工数だけ完成させて終了（完走なら低確率で素材が返る）
  • 判定はCP・耐久・IQからの概算モデル。境界線上では自分の感覚を優先してよい

状態変化の効果と対応

状態効果基本の対応
高品質品質1.75倍（コスモツール効果）。専用技が使える集中加工(150%×1.75、IQ+2)が主砲。CPが底なら秘訣でCP+20。仕上げ域ならビエルゴ
高進捗作業系の進捗+50%工数を残しているなら下地作業/模範作業で一気に稼ぐ
高能率CP消費が半分マニピュレーション/長期倹約/パーフェクトメンドなど重いバフをここで撃つ
頑丈耐久消費が半分耐久10消費の技（精密作業/加工系）を撃つ。倹約加工より素加工が得
頑強耐久消費が半分＋次ターンは必ず頑丈半減が2ターン確定。下地加工2連打など耐久の重い技を惜しまず撃つ
安定成功率+25%突貫作業を使う構成なら価値大。本構成では通常運用でOK
長持続このターンに使ったバフ+2ターンマニピュレーション/イノベーション/ヴェネレーションをここで撃つ
通常-倹約加工でIQ積み、または計画通りの手

※「良兆候」（次ターン高品質の予告）はこのレシピでは出ない。高品質は不意に来るので、来たときに何を撃つか常に決めておくのがコツ。

全体の流れ（3フェーズ）

① 工数フェーズ（ターン1〜7目安）

  • 開幕確信（進捗300% + 次の作業系+100%）
  • ヴェネレーション → 下地作業（確信バフに乗せて大きく進める）
  • 高進捗が来たら下地/模範作業、高品質が来たら集中作業
  • 目標: 残り工数を568以下（模範作業1回分）にして止める。押し込みすぎ注意（最終確認で保険も可）

② 品質フェーズ（IQ10まで積む）

  • 基本は倹約加工（耐久5でIQ+1）。頑丈・頑強が来たら素の加工系、高品質が来たら集中加工(IQ+2)か秘訣
  • 耐久管理はマニピュレーション優先。高能率のターンで撃てると理想（96→48CP）
  • 高品質を1回も引けない時の保険に一心不乱（1回だけ集中加工/秘訣を条件無視で使える）
  • IQ10になったら匠の神業（耐久0で品質上げ）とイノベーションを絡めて品質を伸ばす
  • 頑丈・頑強のときは下地加工（200%・IQ+2）が耐久10で撃てて最効率（頑強なら次ターンも頑丈確定で2連打可）。倹約中・頑丈時のIQ積みは加工→洗練加工コンボ（洗練はIQ+2）
  • CPが尽きたらヘイスティタッチ（CP0・成功率60%）がタダで振れるサイコロ。成功直後はデアリングタッチ（CP0・150%・60%）に繋がるので必ず使う
  • 工数フェーズで耐久が細いときは倹約作業（耐久5・180%）。※匠の早業は高難度レシピでは使用不可（ボタンも常に無効）

③ 仕上げ「グレスト祈り」（IQ10からが本番）

  • 素のビエルゴだけでは31500に届かないことが多い。イノベ＋グレストを維持したまま経過観察や設計変更で流し、高品質(1.75倍)が来た瞬間にビエルゴを叩き込むのが勝ち筋
  • 高品質ビエルゴ（IQ10・GS・イノベ込み）はコスモツール効果込みで一撃約9,000。新式より一発が重く、祈りの回数が減る
  • 残り品質と「ビエルゴ見込」チップ（通常／高品質1.75倍の両方を表示）を見比べて、届くならためらわず撃つ
  • 待てるのはGSが残っている間だけ。GSは3ターンなので観察で流せるのは実質2回、GS残り1になったら状態問わず撃ち切る（設計変更が残っていればターン消費なしで最後の引き直しが可能）。撃たずにGSを切らすのは32CPの丸損で、時限EX+実戦でもこの規律が勝敗を分けた
  • 品質31500を超えたら模範作業で完成。耐久が足りない時は匠の絶技（消費0）を仕上げに残しておくと安全

実際にクリアした人の弁: 「IQ10からが本番」「グレストコンボで高品質お祈り」「下振れしても最後まで完走させろ（低確率で素材が戻る）」

見切りライン（リカバリー判断）

  • CPが200を切って品質が2万に届いていない → 完走しても31500に届かない公算大。素材温存のため工数を完成させずに破棄も選択肢（このシミュでは「最初から」）
  • 設計変更（3回）は「高能率待ち」「高品質待ち」に使う。終盤のビエルゴ直前が最も価値が高い
  • クイックイノベーションはCP0でイノベ1ターン。ビエルゴ直前でCPが足りない時の非常口

計算の前提（このシミュの数値根拠）

  • レシピ: rlvl776 / 除数180・180 / 補正100%（XIVAPI実データ。効率はLv100通常レシピと同じ）
  • デフォルトはコスモツール最終（スターズ: 作業+1842/加工+976/CP+8）＋防具新式想定: 作業精度5779 → 100%効率あたり進捗323、加工精度5502 → 品質340、CP657（設定タブで変更可、食事薬のCPも反映）
  • コスモツールの特殊効果「高品質」時の品質上昇量1.75倍（通常道具は1.5倍）を品質計算・おすすめ・勝算判定に反映済み。新式装備で挑む場合は新式版を使うこと
  • 出る状態は【通常・高品質・高進捗・高能率・頑丈・頑強・安定・長持続】の8種のみ。最高品質・不調・良兆候は高難度レシピでは出ない（検証者のリストと仕様解説で確認済み）。頑強（耐久半減＋次ターン必ず頑丈）は実プレイで確認済み
  • 状態変化の出現率は実機ミラー実測ベース（2026-08-18・部材48T/44サンプル: 頑丈17% / 頑強10% / 高品質10% / 高進捗9% / 高能率14% / 安定10% / 長持続9% / 通常21%、頑強の翌ターンは必ず頑丈）。頑丈系がターンの4割前後、高品質は旧推定の半分。サンプルが増えたら CONDITIONS の数値を更新して精度を上げる
  • 「おすすめ」はあくまで判断の目安。機械的におすすめだけを追った自動テストでは完走成功率は数%だった（惜敗2.9万台が多数）。状態の引きに合わせた人間の判断——特にビエルゴを撃つ/待つの見極め——で上積みするのが本番

※ 3欄とも飯・薬・マイスター込みで「ゲーム画面に出ている実数値」を入れる（作業/加工＝キャラ画面、CP＝製作画面の最大値）。個別ボーナス欄は廃止。変更は「最初から」を押した次の製作から反映されます。
