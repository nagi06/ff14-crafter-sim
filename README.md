# ルインド・アクアダクト中間素材 製作シミュレーター

FF14 パッチ7.55 の庭具「ルインド・アクアダクト」の中間素材3種
（部材 / 金属材 / 錬金樹脂、いずれも同一数値の高難度レシピ）を
**手打ちで攻略するための練習・追従シミュレーター**です。

👉 **[ブラウザで開く](https://nagi06.github.io/ff14-crafter-sim/)**（GitHub Pages）

## バージョン構成

| ページ | 想定装備 | 高品質時の品質倍率 |
|---|---|---|
| [コスモツール版](https://nagi06.github.io/ff14-crafter-sim/cosmo/)（推奨） | 主道具コスモツール最終「スターズ」＋防具新式（作業5779 / 加工5502 / CP657） | **1.75倍**（ツール特殊効果） |
| [新式版](https://nagi06.github.io/ff14-crafter-sim/shinshiki/) | 新式ゴールデンサム／ピーコック装備（作業5657 / 加工5417 / CP649） | 1.5倍 |

いずれも設定タブで自分の実数値に変更できます（必要作業精度5620）。
今後、装備更新に合わせてバージョンを追加予定。

### おまけツール

- **[マクロメーカー](https://nagi06.github.io/ff14-crafter-sim/macro-gen/)** —
  コスモミッションなど毎回数値が違うレシピ用のマクロ自動生成。
  工数・品質・耐久・ステータスを入力すると「最終確認で工数1残し→品質積み→ビエルゴ→完成」型の
  2段マクロを生成する。入力値はブラウザに記憶される（コスモツールの強化で変わるステータスに追従）

## 特徴

- 単一HTMLファイル・依存ライブラリなし・オフライン動作・スマホ縦画面UI
- レシピ実データ準拠（rlvl776 / 工数11250 / 品質31520 / 耐久60 / 完成ライン品質31500）
- 全クラフタースキル実装（マイスター専用・成功率制スキル含む）、公式日本語名
- 状態変化: 通常 / 高品質 / 高進捗 / 高能率 / 頑丈 / 頑強 / 安定 / 長持続（高難度レシピ仕様に準拠。最高品質・不調・良兆候は出ない。頑強の翌ターンは必ず頑丈）
- **練習モード**: 状態変化を自動抽選して手順を練習
- **実機モード**: ゲームに出た状態変化・突貫等の成否を入力してシミュを実機に同期
- **リカバリー入力**: ズレたら現在値を入力してその地点から再開
- **勝算判定**: 毎ターン「続行推奨 / お祈り圏 / 見切り推奨」を表示
- 状態に応じた「おすすめ手」を理由つきで提示

## 注意

- 状態変化の出現率は推定値です（各 `index.html` 内 `CONDITIONS` で調整可）
